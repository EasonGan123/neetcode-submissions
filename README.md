# NeetCode Submissions

My solutions to data structures and algorithms problems from [NeetCode](https://neetcode.io), written in Python. Each accepted submission is synced here automatically, so the history shows how a solution evolved as well as where it ended up.

## Layout

```
<topic>/
  <problem>/
    submission-0.py   first accepted attempt
    submission-1.py   later revision
```

Higher numbers are later attempts at the same problem, usually a cleaner approach or a better time complexity.

## Topics so far

- **Arrays & Hashing**: anagram checks and grouping, two sum, top K frequent elements, string encode and decode
